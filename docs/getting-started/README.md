# Getting started

Set up Aviary, verify its reference data, and run a first analysis.

1. [Install Aviary and configure databases](/installation).
2. Use the [quickstart](/getting-started/quickstart) for the shortest useful run.
3. Follow the [first complete analysis](/getting-started/first-analysis) to learn
   how inputs, stages, outputs and logs fit together.

For production work, also read [reproducibility](/advanced/reproducibility)
before starting the analysis.
